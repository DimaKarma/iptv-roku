# IPTV Player for Roku

## Установка через скрипт деплоя (Windows)
1. Включите Developer Mode на телевизоре Roku: `Home x3, Up x2, Right, Left, Right, Left, Right`.
2. Задайте пароль и запишите IP телевизора.
3. Откройте `deploy.ps1` и впишите ваши `RokuIp` и `RokuPass` в начале скрипта.
4. Запустите скрипт `deploy.ps1` в PowerShell. Он автоматически соберёт ZIP-архив и загрузит его на ТВ.

## Установка вручную
1. Соберите в ZIP-архив файлы `manifest`, `config.json`, папки `source`, `components` и `images` (обратите внимание, что файл `manifest` должен лежать в корне архива, а не в папке).
2. Откройте браузер на ПК и перейдите по адресу: `http://<ROKU_IP>`.
3. Введите логин `rokudev` и ваш пароль от Developer Mode.
4. Нажмите **Upload**, выберите созданный ZIP-архив.
5. Нажмите **Install**.

## Отладка
Для просмотра логов и ошибок BrightScript используйте telnet:
```cmd
telnet <ROKU_IP> 8085
```
Если `telnet` не установлен в Windows, вы можете включить его в "Включение или отключение компонентов Windows", либо использовать PuTTY (тип подключения: Raw, порт 8085).
